# Claude Certified Architect – Foundations Reviewer

ReviewLab is a Next.js reviewer with study content, quick quiz, mock examination, progress tracking and responsive layouts.

Source project upload in progress. The final source is based on the user's latest ReviewLab package.

> **Attribution:** Mock-exam questions are adapted from Matthew Purcell's independent practice set. These are not official exam questions. Obtain the author's permission before redistributing adapted questions publicly.

## Run locally

```bash
npm install
npm run validate
npm run dev
```
